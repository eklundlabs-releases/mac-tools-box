# MacToolsBox releases

Downloads of MacToolsBox for Mac. The source is not here; this repository only holds the releases.

**[Download the newest version](https://github.com/eklundlabs-releases/mac-tools-box/releases/latest/download/MacToolsBox-arm64.dmg)**

For Apple Silicon Macs. Open the disk image and drag MacToolsBox onto Applications. After that it
updates itself.

Every version and what changed in it: [Releases](https://github.com/eklundlabs-releases/mac-tools-box/releases).
